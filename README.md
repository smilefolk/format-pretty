# FormatPritty

เว็บเครื่องมือ JSON ที่ทำงานฝั่งเบราว์เซอร์ทั้งหมด — ข้อมูลที่วางลงไปไม่ถูกส่งออกไปที่ไหน

สร้างด้วย React + Vite ไม่มี dependency อื่นนอกจาก `react` / `react-dom`
(ตัวตรวจไวยากรณ์ JSON, syntax highlighting, มุมมองต้นไม้ และตัวเทียบข้อมูล เขียนเองทั้งหมด)

## ฟีเจอร์

### 1. จัดรูปแบบ JSON

- จัดรูปแบบ (`⌘/Ctrl + Enter`) และย่อขนาด เลือกระยะเยื้อง 2 ช่อง / 4 ช่อง / แท็บ
- เรียงคีย์ A→Z, มุมมองโค้ดพร้อมเลขบรรทัด หรือมุมมองโครงสร้างแบบพับ/ขยายได้
- ตรวจสอบสดขณะพิมพ์ บอกสาเหตุเป็นภาษาไทยพร้อมบรรทัด/คอลัมน์ที่ผิด และไฮไลต์บรรทัดนั้น
- วาง JSON หลายก้อนต่อกันได้ (NDJSON, `{...}{...}`, `{...},{...}`) ระบบรวมให้เป็นอาร์เรย์อัตโนมัติ
- เปิดไฟล์หรือลากไฟล์มาวาง, คัดลอก, ดาวน์โหลด, สถิติ (บรรทัด ขนาด จำนวนคีย์ ความลึก)

### 2. เปรียบเทียบ 2 ก้อน

เทียบ JSON สองก้อนแบบลึกทุกระดับ แยกความต่างเป็น 4 ชนิด: ค่าต่างกัน, ชนิดข้อมูลต่างกัน,
มีเฉพาะฝั่งซ้าย, มีเฉพาะฝั่งขวา พร้อมเส้นทางแบบ `$.profile.city` / `$.roles[1]` (คลิกเพื่อคัดลอก),
ตัวกรองตามชนิด, สลับซ้าย–ขวา และคัดลอกรายงานเป็นข้อความ

วางสองก้อนในช่องซ้ายช่องเดียวแล้วเว้นช่องขวาไว้ก็ได้ ระบบจะแยกให้เอง

> รายการในอาร์เรย์เทียบตามลำดับ (index) ไม่ใช่จับคู่ด้วยคีย์

### 3. สตริง → JSON

แกะ JSON ที่ถูก escape เป็นสตริงกลับมาเป็นข้อมูลจริง รองรับทั้งแบบมีเครื่องหมายคำพูดครอบ
(`"{\"a\":1}"`) และแบบวางมาดิบ ๆ (`{\"a\":1}`) รวมถึง escape ซ้อนหลายชั้น
และมีตัวเลือกแกะสตริง JSON ที่ซ่อนอยู่ในฟิลด์ย่อยด้วย (เช่น `payload` ในล็อก) แล้วส่งต่อไป
หน้าจัดรูปแบบได้ในคลิกเดียว

## การพัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # build ไปที่ dist/
npm run preview  # เสิร์ฟไฟล์ที่ build แล้ว
```

## โครงสร้าง

```
src/
  App.jsx           เปลือกนอก: เมนู ธีม และ state ของทุกหน้า
  pages/            Formatter · Compare · Unwrap
  components/       Editor (textarea + เลขบรรทัด) · CodeView · JsonTree
  lib/
    locate.js       ตัวตรวจไวยากรณ์ JSON ที่เขียนเอง (ระบุตำแหน่งผิด + แยกหลายก้อน)
    json.js         parseJson / จัดรูปแบบ / สถิติ / tokenizer
    diff.js         เปรียบเทียบแบบลึก
    unwrap.js       แกะสตริง JSON
```

ตัวตรวจไวยากรณ์เขียนเองเพราะข้อความ error ของ `JSON.parse` ในเบราว์เซอร์มักไม่บอกตำแหน่ง
(เช่น `Unexpected token ',', ..."..." is not valid JSON`) ทำให้ชี้บรรทัดที่ผิดให้ผู้ใช้ไม่ได้
